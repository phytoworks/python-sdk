# Contributing

This repository is a read-only mirror. `phytoworks` is developed in a private
monorepo, and each PyPI release is mirrored here as one commit and one `vX.Y.Z`
tag whose files match the sdist published on PyPI.

- **Pull requests are not accepted.** A pull request cannot be merged, because
  the next release replaces the tree.
- **Issues are welcome:** bug reports and feature requests, using the forms.
- **Never paste keys, tokens or session files** into an issue, a comment or a
  log. Redact them first; report a leak through [SECURITY.md](SECURITY.md).

To install a release from PyPI: `pip install phytoworks==X.Y.Z`.
